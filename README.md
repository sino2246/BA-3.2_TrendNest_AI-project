# TrendNest – AI-Powered Retail Demand Forecasting
## 1. Project Overview
TrendNest is an AI and Python group project that explores retail demand forecasting using historical sales data. It aims to help retailers make better inventory decisions through data analysis and forecasting.

## 2. Problem Statement
Retailers may experience overstocking or stock shortages, which can increase business costs and affect customer satisfaction. TrendNest explores how historical sales data can help identify demand patterns and support better inventory planning.

## 3. Project Objectives
- Analyse historical retail sales data.
- Identify high-demand products.
- Explore sales trends and patterns.
- Support better inventory planning.
- Help reduce overstocking and stock shortages.

## 4. Project Features
- **Data cleaning:** Prepare retail data for analysis.
- **Demand forecasting:** Analyse historical sales to estimate future demand.
- **Data visualisation:** Present sales patterns and insights.
- **Chatbot:** An additional feature for user interaction.

## 5. Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- VS Code
- GitHub

## 6. Dataset
The project uses the Online Retail dataset from the UCI Machine Learning Repository.

The original dataset contains retail transaction information, including product codes, quantities, invoice dates, unit prices and customer details.

The Excel dataset is stored in the project's `data` folder.

## 7. Project Structure
- `main.py` – Main data loading and cleaning script.
- `forecast.py` – Forecasting component.
- `chatbot.py` – Chatbot component.
- `data/` – Dataset and generated data files.
- `.gitignore` – Specifies files excluded from Git tracking.
